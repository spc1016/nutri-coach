# NutriCoach

**NutriCoach** es la aplicación móvil oficial cliente diseñada para acompañar a los usuarios de clínicas de nutrición y entrenadores personales en su progreso físico. Esta aplicación Android orientada a clientes proporciona de forma rápida y sencilla acceso directo a las dietas personalizadas, rutinas de entrenamiento y un seguimiento del progreso a través de notas.

## 🚀 Características Principales

*   **Gestión de Perfil:** Visualiza y actualiza los datos biométricos (peso, altura, edad, etc.) y objetivos personales al instante.
*   **Dietas Personalizadas:** Explora los planes alimenticios asignados por el profesional, visualizando un sistema de comidas detallado con alimentos, calorías y notas por cada comida y día. 
*   **Rutinas de Entrenamiento:** Verifica las rutinas programadas divididas por días, e inspecciona cada uno de los ejercicios asignados, repeticiones y cargas a realizar.
*   **Cuaderno de Notas:** Registra y lleva un historial privado de pensamientos, resultados y sensaciones para realizar un seguimiento a largo plazo de tu proceso físico.
*   **Autenticación Segura:** Diseño protegido mediante credenciales y control de sesión a través de tokens web (JWT), manteniendo todos tus informes de salud protegidos localmente.

## 📲 Requisitos Previos

- **Android Studio** instalado (preferiblemente Iguana o superior para compatibilidad con el compilador KSP).
- **Dispositivo Físico o Emulador** corriendo **Android 10 (API Level 29)** o superior.
- **Conexión a Internet** activa para sincronizar los datos del servidor (MongoDB).
